Contact Book (Console App)

A simple command-line contact management system written in Python. Built as a practice project to apply functions, lists of dictionaries, and control-flow patterns (loops, break, for/else) in a real mini-application.

Features
Add contacts — enter multiple names and phone numbers in one session, exit anytime by typing exit
Search contacts — look up a contact by name; keeps prompting until found or you type exit
Display all contacts — view every saved contact in the list
Simple menu-driven interface — navigate via a text menu (Add, Display, Search, Exit)
Concepts practiced
Functions with return values (returning lists of dictionaries)
while/for loops, break, and the for...else pattern for search logic
List manipulation with .append() and .extend()
Basic input validation and control flow
